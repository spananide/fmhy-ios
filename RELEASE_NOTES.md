**What's new in 1.6.0**
- **Redesign:** the whole app now uses native iOS lists, pickers and toolbars
- Settings as native pickers, a "Report" action in the toolbar, left-aligned onboarding
- Cleaner Following, What's new, search help and link check screens with proper empty states
- Browser: new start page, safety sheet, protections and site settings, tab switcher toolbar
- Fewer colors, better accessibility labels, error alerts instead of silent failures

**Install:** download the `.ipa` below and sideload it with [Sideloadly](https://sideloadly.io), SideStore/AltStore, or on Linux with Sideloader/iloader. Details in the [README](https://github.com/spananide/fmhy-ios#install-free-no-mac-needed).

iOS port of FMHY for Android (omeg4-dev); a community app, not an official FMHY project. Feedback: [open an issue](https://github.com/spananide/fmhy-ios/issues/new/choose).
