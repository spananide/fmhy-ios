**What's new in 1.5.1**
- **Beginner's guide** opens as a proper reading page (open it from the sections list)
- **Downloads:** notification when a download finishes or fails, and the speed is shown while downloading
- "Full report" now opens inside the app, and is hidden when VirusTotal does not know the file or link yet
- Failed downloads show the error code

**Install:** download the `.ipa` below and sideload it with [Sideloadly](https://sideloadly.io), SideStore/AltStore, or on Linux with Sideloader/iloader. Details in the [README](https://github.com/spananide/fmhy-ios#install-free-no-mac-needed).

Official iOS port of FMHY for Android (omeg4-dev); a community app, not an official FMHY project. Feedback: [open an issue](https://github.com/spananide/fmhy-ios/issues/new/choose).
